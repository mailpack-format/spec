# Conformance corpus

The public conformance corpus: synthetic pathological messages, multi-part-export
shapes, and byte-variant pairs of the *same* logical message (e.g. IMAP-fetched vs.
Takeout-munged vs. PST-synthesised) with hand-labeled ground truth for logical
identity.

Correctness of an identity version is defined against this corpus.

Real-world horror fixtures containing PII live in a private repository and are pulled
only in CI; nothing here may contain personal data.

Empty for now; populated alongside identity v1.
